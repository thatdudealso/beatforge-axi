BeatForge AXI

Local-first music generation with an agent-oriented CLI and CueLab deck UI. Open engines only, permissive model provenance only, MP3 export first.

Agents

Use terse TOON commands for generate, repaint, remix, stems, and analysis.

Humans

CueLab provides the same operations as a turntable-style local web UI.

Engines

ACE-Step, YuE, and MusicGen sit behind one pluggable adapter contract.
