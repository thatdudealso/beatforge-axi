# Contribution brief: Finish beatforge-axi to contributable state (real audio, no fake engine)

## Problem
beatforge-axi is a local-first open-source music generation AXI tool with full engine contracts, manifest parity for CLI/API/CueLab, and Phase 0-4 scaffolding. However:

- The `/v1/jobs/{operation}` endpoint only queues; it does not execute engines or return playable artifacts.
- The only working "engine" is the `fake` engine, which writes placeholder bytes (not real audio).
- No artifact serving (`/v1/artifacts/...`).
- No FFmpeg post-processing (normalize, trim/pad, MP3 export).
- CueLab UI submits jobs but cannot play or export real audio.
- Feature tracks and READMEs still document "scaffold" state.
- This blocks the required user workflow: Generate a track → API returns real artifact URL → CueLab loads + plays it in browser (Web Audio) → Export as MP3.

User explicitly requires: **the fake engine must not be present** in the finished/contributable state. All generation must produce real, playable audio locally.

This work is needed before catalog submission to https://github.com/kunchenguid/axi (following its CONTRIBUTING.md which mandates `no-mistakes` for PRs).

## Expected
- Real local job execution with status (queued → running → done/error), progress via SSE.
- Stable artifact IDs with safe streaming at `/v1/artifacts/{id}` (no arbitrary FS exposure).
- A lightweight, fully local, open-source real engine (no heavy model weights required for basic testing) that generates actual waveform audio (WAV internally, MP3 as user-facing default).
- FFmpeg pipeline: loudness normalization, exact duration trim/pad, MP3 export.
- CueLab receives artifact URLs, has working play/pause/seek + duration display, and working Export MP3.
- End-to-end: Generate (CLI or UI) → real audio file → play in browser deck → export MP3.
- All docs updated honestly (distinguish dev synth from future ACE-Step).
- Fake engine removed from default/runtime paths (kept only in isolated test files if needed, clearly marked).
- Passes: `uv run ruff format --check .`, `ruff check .`, `basedpyright`, `uv run pytest`, `corepack pnpm run build` (in cuelab-axi).
- Playwright + manual browser verification of the full workflow.
